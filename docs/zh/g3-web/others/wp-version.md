# WordPress 版本选择

> 现代 WordPress 一直在努力抛弃历史包袱，拥抱时代特性。

软件并不是越新版越好！摈弃不需要的功能，选择合适的版本，才能获得最佳的性能和安全性。

G3-Web 为大家整理和介绍 WordPress 各大版本的核心功能，辅助用户选择合适的版本。所有信息主要针对服务端核心特性，不关注前端交互。

访问 WordPress 官网 [Release Archive](https://wordpress.org/download/releases/) 查看和下载对应版本的最新子版本。

## 6.5 翻译、JSON 解析

::: success 解决
底层解析与翻译性能优化。
:::

- **高性能翻译系统**：将 `Performant Translations` 特性插件合并入核心。引入了全新的 `.l10n.php` 翻译文件格式，相比传统的 `.mo` 和 `.po` 文件，大幅提升了翻译加载速度并降低了内存占用。
- **HTML API 重大更新**：底层的 HTML 标签处理器（Tag Processor）经历了重大重构，现在支持更大范围的 HTML 规范，为后端解析 HTML 内容提供了更强大的基础。
- **脚本模块 API**：在核心层面原生引入了对 `JavaScript Module` 的支持，改变了以往脚本加载的底层机制，提升了资源加载效率。
- **区块变体注册性能提升**：优化了使用回调函数注册区块类型变体（Block Variations）的性能表现。

## 6.6 缓存减负

::: success 解决
核心渲染与缓存机制优化。
:::

- **主题 JSON 配置的性能优化**：移除了冗余的 `WP_Theme_JSON` 类调用，减少了不必要的后端开销。
- **选项自动加载限制**：禁用了大尺寸选项（Options）的自动加载，减轻了数据库查询压力。
- **消除不必要的 Polyfill**：清理了底层依赖中不必要的 polyfill 依赖项，精简了核心代码体积。
- **异步交互指令**：后端引入了新的 `data-wp-on-async` 指令，改变了交互事件在后端的处理与绑定机制。
- **文章类型自动保存控制**：各个自定义文章类型（Post Types）现在可以在后端选择退出（Opt-out）自动保存功能，为开发者提供了更精细的控制权。

## 6.7 媒体处理、PHP 8

::: success 解决
媒体处理与 HTML 解析增强。
:::

- **懒加载图片尺寸自动调整**：后端会自动为懒加载图片的 `sizes` 属性添加 `auto` 值（通过 `wp_img_tag_add_auto_sizes()` 函数），优化了响应式图片在后端的渲染逻辑，提升页面加载性能。
- **HTML API 标签处理优化**：进一步提升了 HTML API 中标签处理的执行效率。
- **PHP 8+ 支持改进**：优化了对 PHP 8 及以上版本的支持，并在核心中清理了部分已废弃的代码。

## 6.8 密码安全、数据库

::: success 解决
安全性与数据库查询性能。
:::

- **Bcrypt 密码哈希加密**：核心安全机制的重大升级。弃用了旧有的 phpass 框架，全面采用 bcrypt 哈希算法存储密码，极大增强了抵御暴力破解攻击的能力，且此过程对用户和开发者完全透明、自动生效。
- **数据库查询缓存优化**：继续优化 WP_Query 类中缓存键（Cache Keys）的生成机制，显著减轻了高流量网站的数据库负担。
- **区块类型注册加速**：底层加快了区块类型的注册流程，配合查询缓存，进一步减少了后端响应延迟。

## 6.9 架构升级

::: success 解决
系统级 API 与前端渲染架构革新，为 AI 铺路。
:::

- **能力 API**：引入了全新的统一能力注册系统。允许开发者在 PHP、REST API 甚至 AI 智能体上下文中，以标准化的方式一致地注册、验证和执行操作。
- **流式块解析器（Streaming Block Parser）**：引入了全新的区块解析机制，改变了核心处理区块内容的底层方式，为未来的性能优化打开了大门。
- **前端性能与资源调度优化**：改进了条件样式表和内联样式表的加载逻辑，支持按优先级加载脚本，并降低了非关键脚本的优先级以清理渲染路径，显著改善了 LCP（最大内容绘制）指标。
- **WP Cron 启动改进**：优化了 WordPress 内置定时任务（WP Cron）的触发与启动机制。
- **模板增强输出缓冲区**：引入了新的输出缓冲区机制，提升了模板渲染的底层效率。
- **HTTPS 默认协议支持**：URL 转义函数现在支持将 HTTPS 作为默认协议，提升了核心安全基线。
- **邮件功能增强**：对底层的邮件发送功能进行了重构，使其更加可靠。
- **废弃 IE 遗留代码**：彻底移除了针对 Internet Explorer 的旧版兼容代码，精简了核心代码库。

## 7.0 AI 集成

::: success 解决
AI 集成与智能体支持。
:::

- AI 客户端与统一连接器：核心引入了 AI Client，允许 WordPress 直接与生成式 AI 模型通信。后台新增了统一的“连接器（Connectors）”枢纽，集中管理 OpenAI、Claude、Gemini 等外部 AI 服务。
- 能力 API：为插件和 AI 智能体提供了一个标准化的方式，在 PHP、REST API 甚至浏览器端声明、注册和执行操作，支持跨插件的自动化工作流。
- MCP 适配器：实现了模型上下文协议（MCP），允许 Cursor、Claude 等外部 AI 助手直接读取网站功能并触发操作。
- 运行环境门槛提升：最低 PHP 运行环境要求提升至 7.4。
- 纯 PHP 区块注册：引入了仅依赖 PHP 的区块注册机制和自动生成的检查器控件。
- 区块级自定义 CSS：允许用户在编辑流程中直接为单个区块编写 CSS 样式，自动样式注入。
- REST API 扩展：新增 /wp/v2/icons 等端点，支持后端 SVG 图标注册与搜索。
- 移除：多人实时协同编辑功能。
- 全局命令面板：后台新增全局命令面板（支持 ⌘K / Ctrl+K 快捷键）。

## 7.1 响应式设计、媒体处理

::: success 解决
编辑器原生响应式样式与浏览器端媒体处理。
:::

- 编辑器响应式样式：区块样式现在可直接按屏幕尺寸（桌面、平板、手机）分别设置，无需编写自定义 CSS。Block 主题可在 theme.json 中定义自己的移动端和平板端断点。
- 交互状态样式：按钮等区块可在编辑器中直接设置 悬停（hover）、焦点（focus）、激活（active） 状态的样式，替代了以往需要手写 CSS 的做法。
- 浏览器端媒体处理：图片的压缩、调整尺寸和缩略图生成现在优先在用户浏览器中完成（基于 WebAssembly 版 libvips），再上传到服务器，降低 PHP 内存限制和上传超时的风险。
- 原生支持现代图片格式：新增对 AVIF、HEIC 以及 HDR gain maps 的原生支持，更好地适配现代手机和相机生成的图片。
- 全新媒体编辑器：将自由裁剪、固定比例裁剪、水平/垂直翻转、精确旋转及元数据编辑整合到一个弹窗界面中，替代了旧版的简单裁剪工具。
- Notes 协作功能增强：注释可附加到选中的具体文字片段而非整个区块，支持富文本格式（加粗、斜体、代码、链接）以及 @提及协作者并发送邮件通知。
- 新增核心区块：加入了 Tabs（选项卡） 和 Playlist（播放列表） 区块，覆盖标签页内容和音频集合展示需求，减少了对插件的基本依赖。
- SVG 图标 API：开发者可以注册和扩展自定义图标集合，使其在编辑器图标库中可用。
- 管理栏全局可用：后台管理栏（Admin Bar）现在在站点编辑器和文章编辑器中均保持可见，提供跨界面的一致性导航体验。
