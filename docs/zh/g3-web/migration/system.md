# 系统迁移

## 背景

随着业务的发展，您会对系统性能和成本核算提出越来越高的要求。

`G3-Web` 支持将初期由 `WP` 快速构建的业务系统，无缝迁移到更优性能的平台。

## 方案

我们提供了四种高性能系统升级方案：

- PHP: Webman
- Rush: Axum

## 无缝升级

整个迁移和升级过程不影响业务运行，无缝升级和切换。

## 服务

由于涉及部署实施和数据安全问题，该服务与业务顾问和团队建设配套，仅面向线下高级用户提供升级与迁移服务。
