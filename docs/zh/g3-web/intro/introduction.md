# 简介

G3-Web 是一个现代化的 `WordPress`（之后简称 WP） 主题框架，它以插件的形式发布，为 WP 提供横向（系统应用层）和纵向（开发扩展层）的扩展，旨在：

帮助用户快速构建强大的 WP 主题或 Web 应用系统，快速服务业务：

- 增强 WP 应用程序的能力，更好地满足现代数字化运营的需求。
- 帮助 WP 用户快速构建功能完善、稳定的 Web 项目，并轻松维护。
- 帮助中小创业者以超低成本快速实现跨平台运营、业务实验、系统私有化。
- 帮助任何有创意的用户，将他们的想法转化为数字解决方案。

## 为什么选择 G3 Web

- **支持性付费**：近乎零成本，快速实现数字资产私有化。
- **应用丰富**：内置十几种满足现代运营需求的子系统，开箱即用，帮助你快速私有化搭建运营系统。
- **设计即方案**：用 HTML 表达你的设计想法，用 G3-Web 把 HTML 变成动态 Web 应用，快速实现数字解决方案。
- **极速开发**：丰富的业务系统支持和接口，开箱即用，一天完成一个 Web 应用。
- **SEO 友好**：你可以自定义任何页面或内容的 SEO 信息，自定义它们在被分享到不同社交平台时的标题等信息，让搜索引擎更友好。
- **AI 友好**：通过规范的 llms.txt 和 Markdown 文件，让 AI 更容易理解和使用你的系统和业务。
- **扩展与安全**：通过组件系统与配置机制，你可以轻松扩展系统功能组件和更新安全策略。

## 核心特性

### 架构特性

- **组件化架构** - 组件系统支持模块化、按需加载，灵活解耦和扩展。
- **控制器路由** - 基于注解和控制器的 REST API 路由系统
- **中间件支持** - 便捷的中间件机制，完善 API 权限控制
- **Rewrite** - 基于配置文件和依赖管理的重写系统
- **PSR-11 容器** - 符合 PSR-11 标准的依赖注入容器
- **AOP 编程** - 支持基于注解的切面编程
- **现代化 PHP 8.3+** - 使用最新的 PHP 特性和语法

### 功能模块

- **队列系统** - 异步任务处理，支持消息队列和任务队列
- **缓存系统** - Redis 对象缓存支持
- **安全防护** - 多层安全防护机制
- **内容管理** - 增强的文章管理、浏览统计、版权保护
- **用户认证** - 支持微信登录、社交登录
- **电商功能** - 商品管理、订单系统、SKU 管理
- **微信集成** - 微信公众号管理、消息处理
- **支付系统** - 支持多种支付方式集成
- **客服系统** - 支持客服消息处理、客服工单管理
- **等等**

::: warning 注意
系统和功能虽然丰富，但这些功能并不是强制加载和启用的。

只有当您允许使用指定系统或功能组件时，它才会加载和启用。
:::
