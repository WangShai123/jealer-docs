# 服务

## 支持性付费

我们期望用户在创业时有一个轻松的开始，因此我们提供了近乎零成本的支持性付费模式。用户可以仅支付近似一顿火锅的费用 `280 元/年`，即可获得 G3 Web 全面的支持性服务，帮助用户快速实现数字资产私有化。

如果您的业务发展顺利，三年之后，仅收取 `10 元/年`，保持长期技术支持，以全面地支持您的业务发展。

## 高阶付费服务

如果您需要，我们也提供了更高阶的付费服务：

- 业务顾问
- 团队规划与建设
- 系统定制与优化

## 在线授权

您可以在 [JEALER](https://www.jealer.com) 网站上申请对应服务，获取服务授权。

为保证业务服务质量，高阶服务每月仅限 2-5 个名额。
