# 准备工作

你需要确保已经完成了以下准备工作：

## 基础知识

- 认识网络应用
- 了解 Web 开发基础 HTML、CSS、JavaScript
- 认识 HTTP 网络通信协议
- 了解 PHP 基础语法
- 认识 MySQL 数据库

若您还不了解这些，建议先访问 [吉木学院](/zh/learn/)，在 `网络应用` 栏目，了解相关知识。

## 环境准备

- 一台可以访问互联网的计算机或服务器
- 安装 Nginx 或 Caddy Web 服务器
- 安装 PHP 8.3 或更高版本
- 安装 MySQL 8.0.46 或更高版本
- 安装 Redis 8.0 或更高版本
- 安装 WordPress 6.9.x 最新版本 或更高版本

若您还不了解这些，建议先访问 [吉木学院](/zh/learn/)，在 `环境准备` 栏目，了解相关教程。

## 工具准备

- 一个浏览器，推荐使用 [Chrome](https://www.google.com/chrome/) 或 [Firefox](https://www.mozilla.org/firefox/)
- 一个代码编辑器，推荐使用 [VSCode](https://code.visualstudio.com/)
- 一个本地服务器环境，推荐使用 [FlyEnv](https://www.macphpstudy.com/zh/index.html)
- 一个本地数据库管理工具，推荐使用 [DBX](https://dbxio.com/)

若您还不了解这些，建议先访问 [吉木学院](/zh/learn/)，在 `工具准备` 栏目，了解相关教程。
